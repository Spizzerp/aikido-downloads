# AIKIDO Android downloads

Signed standalone Android testing builds for AIKIDO.

**[Download AIKIDO v1.0.1 build 1016 APK](https://github.com/Spizzerp/aikido-downloads/releases/download/v1.0.1-1016/AIKIDO-1.0.1-1016.apk)** · **[Release details](https://github.com/Spizzerp/aikido-downloads/releases/tag/v1.0.1-1016)** · **[SHA-256 checksum](https://github.com/Spizzerp/aikido-downloads/releases/download/v1.0.1-1016/AIKIDO-1.0.1-1016.apk.sha256)**

The APK is approximately 190 MB. It targets ARM64 Android phones, including Seeker, and runs without Expo or a connected laptop. Open the APK link on your phone, download the file, and open it to install. Android may ask you to allow installation from your browser.

This is a testing build connected to **Solana mainnet**, using real wallets and funds. Read the release details and review each wallet approval. Known compatibility and testing limitations are listed in the release.

If an installed AIKIDO app uses a different signing key, Android will refuse an in-place update. Uninstalling that app erases its local data; do not do so without preserving what you need. AIKIDO Dev is a separate app.
